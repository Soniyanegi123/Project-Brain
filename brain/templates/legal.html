Data handling

Project Brain stores imported repository records and source files in its configured SQLite database. Treat that database as sensitive project data.

External services

When an OpenAI API key is configured, retrieved evidence and questions are sent to OpenAI for embeddings and answer synthesis. GitHub imports make requests to GitHub services. Do not index confidential code unless your team has approved those services and settings.

Retention

Data remains in the local database until it is replaced or deleted by the operator. This prototype does not provide user-level retention controls.

Prototype terms

Project Brain is a hackathon prototype. Its retrieval, dependency, impact, decision, and contributor-risk outputs are estimates that require engineering review.

Use of repository data

Only import repositories you are authorized to process. The operator is responsible for access control, secrets management, and compliance with third-party API terms.
